## 第一次使用（只做一次）

在 WSL 的 Ubuntu 终端里执行：

```bash
cd ~
git clone https://github.com/tonghao/cloud-app-dev-2026.git
```

**只用 https 开头的地址。**页面上 `git@github.com:` 开头的是 SSH 地址，需要账号和密钥，用不了。
网络不通时，班群里每讲都有同样内容的压缩包。

## 每讲课前

```bash
cd ~/cloud-app-dev-2026 && git pull
```

然后打开进度表最后一行的项目讲义，按讲义把起始代码**复制**到自己的工作区再做。

## 不要在本仓库里改文件

本仓库只读。直接改了这里的文件，下次 `git pull` 会冲突。
万一改了，先把自己的改动挪到 `~/work`，再执行 `git checkout -- .` 恢复。

## 自己的工作区

```
~/work/
├── venv/            第2章所有练习共用的虚拟环境，只建一次（第4讲课前准备）
├── 练习/             拓展练习里不在云书签上做的部分（如改正 AI 代码）
└── cloud-bookmark/  三级项目「云书签」，你自己的 Git 仓库，每讲提交一次
```

每次开工：`cd ~/work && source venv/bin/activate`
