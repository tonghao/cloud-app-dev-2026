# HTML 速查卡（一）　页面

> 课程：云应用开发　|　第5讲用。表单部分见第6讲的「HTML 速查卡（二）表单」。

HTML 在第3章系统学习（教材 3.1）。第5、6讲只要求读懂云书签的模板，并能照着写出新页面。本卡只列云书签用到的标签。

---

## 三条规则

| 规则 | 例子 |
|---|---|
| 标签大多成对：开始标签 `<p>`，结束标签 `</p>`，内容写在中间。少数标签只有一个，不写结束标签：`<meta>`、`<link>`、`<input>`、`<br>`、`<img>`。 | `<p>共 3 条书签</p>` |
| 属性写在开始标签里，格式是 `名字="值"`，多个属性用空格隔开。 | `<a href="/add" target="_blank">` |
| 标签可以嵌套，先打开的后关闭，不能交叉。 | `<ul><li>…</li></ul>` 对；`<ul><li>…</ul></li>` 错 |

另外两点：

- 浏览器把连续的空格、换行当成一个空格。模板里的缩进只是给人看的，不影响页面。
- `<!-- 注释 -->` 里的内容不显示。

## 页面骨架

每个页面都是这个结构。第5讲以后，这部分只写在 `base.html` 里，其他页面继承它。

| 写法 | 作用 | 起始代码 `index.html` | 教材 |
|---|---|---|---|
| `<!DOCTYPE html>` | 声明这是 HTML5 文档，必须在第一行 | 第 1 行 | 3.1.1 |
| `<html lang="zh-CN">…</html>` | 整个文档，`lang` 是页面语言 | 第 2、26 行 | 3.1.1 |
| `<head>…</head>` | 页面的说明信息，不显示在页面上 | 第 3—7 行 | 3.1.1 |
| `<meta charset="UTF-8">` | 字符编码。不写，中文可能显示成乱码 | 第 4 行 | 3.1.1 |
| `<title>云书签</title>` | 浏览器标签栏上的文字 | 第 5 行 | 3.1.1 |
| `<link rel="stylesheet" href="…">` | 引入样式表，浏览器会再发一次请求取它 | 第 6 行 | 2.5.5 |
| `<body>…</body>` | 页面上显示的全部内容 | 第 8—25 行 | 3.1.1 |

## 内容标签

| 写法 | 作用 | 起始代码 `index.html` | 教材 |
|---|---|---|---|
| `<h1>云书签</h1>` | 一级标题，`<h2>`—`<h6>` 依次变小 | 第 9 行 | 3.1.2 |
| `<p>…</p>` | 段落 | 第 24 行 | 3.1.2 |
| `<a href="地址">文字</a>` | 链接。`href` 写地址；`target="_blank"` 在新标签页打开 | 第 11、16 行 | 3.1.2 |
| `<ul>` 加若干 `<li>` | 无序列表，一个 `<li>` 是一项；有序列表用 `<ol>` | 第 14—23 行 | 3.1.2 |
| `<nav>…</nav>` | 导航区，里面放导航链接 | 第 10—13 行 | 3.1.3 |
| `<img src="地址" alt="说明">` | 图片，`alt` 是图片显示不出来时的文字 | 云书签未用 | 3.1.2 |
| `<strong>…</strong>` | 加粗强调 | 云书签未用 | 3.1.2 |

第 18—20 行的 `<form>` 和 `<button>` 是删除按钮，第6讲再讲。

## HTML 与 Jinja2 标记

- `{{ … }}`、`{% … %}` 不是 HTML，是 Jinja2 的标记。服务器渲染时把它们换成 HTML，浏览器收不到（PPT 第 8 页）。
- 标记可以写在标签之间，例如 `<p>共 {{ bookmarks|length }} 条书签</p>`；也可以写在属性值里，例如 `<a href="{{ bm.url }}">`。
- 写好模板后，在浏览器右键「查看网页源代码」，看到的就是浏览器实际收到的 HTML。

---

## 写新页面时（拓展 E1、E3、E5）

1. 第一行写 `{% extends "base.html" %}`，不再写骨架。
2. 标签栏文字写在 `{% block title %}…{% endblock %}` 里。
3. 页面内容写在 `{% block content %}…{% endblock %}` 里，用上面表里的内容标签。
4. 刷新后页面不对时，先查看网页源代码，看标签是否成对、有没有交叉。
