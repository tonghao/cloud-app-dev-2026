## 一　HTML 语法（PPT 第 5—10 页）

**练习 1　改名，看浏览器怎样读**

1. 在 VS Code 左侧把 `棕熊.txt` 重命名为 `bear.html`。
2. 在资源管理器里双击 `bear.html`，用浏览器打开。

问：文本里明明分了行，浏览器里为什么挤成一段？

<details>
<summary>参考</summary>

HTML 里的回车和连续空格都合成一个空格（PPT 第 9 页）。分段、分层次不能靠回车，要靠标签。

</details>

**练习 2　找错**

把下面三行粘贴进 `试验.html`，先判断每行错在哪、浏览器会怎样显示，写下来，再保存、用浏览器打开验证。

```html
<p>棕熊的保护等级是<strong>无危</p></strong>
<p>棕熊是<em>大型杂食动物。</p>
<p><a href=https://baike.baidu.com/item/棕熊/370530 target=_blank>更多...</a></p>
```

<details>
<summary>参考</summary>

1. 交叉嵌套：先开的 `strong` 应当后关，写成 `<strong>无危</strong></p>`。
2. 漏写 `</em>`：浏览器不报错，会把后面的内容也变成斜体，补上 `</em>` 才对。
3. 属性值没加引号。这一行浏览器还能认，但值里一有空格就会断开，属性值一律加引号。

三处浏览器都不报错，只会「猜」着显示（PPT 第 8、9 页）。

</details>

**练习 3　注释与实体**

在 `试验.html` 末尾加两行：一行注释「以下是测试」；一行正文「体长 < 3 米 & 体重 > 100 千克」，要求小于号、和号、大于号照原样显示。

<details>
<summary>参考</summary>

```html
<!-- 以下是测试 -->
<p>体长 &lt; 3 米 &amp; 体重 &gt; 100 千克</p>
```

注释在页面上看不到；`<` 直接写，浏览器会把它当成标签的开头（PPT 第 10 页）。

</details>

## 二　文本与列表（PPT 第 11—15 页）

下面四道练习都在 `bear.html` 里做。**文字一个字不改，只加标签。**

**练习 4　标题的层级**

给所有标题加标签：全页标题「棕熊」；三个大的部分「关于棕熊」「栖息地」「媒体」；它们下面的小节「物种」「特征」「拥有大量棕熊种群的国家」「拥有少量棕熊种群的国家」。层级自己判断，不跳级。

自查：刷新后标题分大、中、小三级；对照 PPT 第 12 页的大纲树。

<details>
<summary>参考</summary>

「棕熊」用 `h1`；「关于棕熊」「栖息地」「媒体」用 `h2`；四个小节用 `h3`。例如：

```html
<h1>棕熊</h1>

<h2>关于棕熊</h2>
```

</details>

**练习 5　段落与列表**

1. 「棕熊（Ursus arctos）原产于……」「棕熊并不总是纯棕色……」「一些棕熊种群较少的国家……」三段，各标成一个段落。
2. 四个物种、三个国家，各标成一个列表。哪个用有序列表、哪个用无序列表，自己判断，说出理由。
3. 「更多...」和下一行网址、「媒体」下的两行地址，暂时各包进一个段落，练习 8、9 再改。

自查：物种前有圆点或编号，国家前有圆点或编号，段与段之间有空行。

<details>
<summary>参考</summary>

物种之间没有先后，用 `ul`；三个国家按种群数量排，有先后，用 `ol`（PPT 第 14 页）：

```html
<h3>物种</h3>
<ul>
  <li>Arctos</li>
  <li>Collarus</li>
  <li>Nelsoni</li>
  <li>Horribilis</li>
</ul>
```

```html
<h3>拥有大量棕熊种群的国家</h3>
<ol>
  <li>俄罗斯</li>
  <li>美国</li>
  <li>加拿大</li>
</ol>
```

</details>

**练习 6　强调**

学名「Ursus arctos」要表示强调，保护等级「无危」要表示重要。各用哪个元素？

<details>
<summary>参考</summary>

```html
<p>棕熊（<em>Ursus arctos</em>）原产于欧亚大陆北部和北美洲的部分地区。它目前的保护等级是<strong>无危</strong>。</p>
```

`em` 表示强调、`strong` 表示重要，不要只为了斜体、粗体用 `i`、`b`（PPT 第 13 页）。

</details>

**练习 7　块级还是内联**（在 `试验.html` 里做）

先判断，再验证：`<p>栖息地：<ul><li>俄罗斯</li></ul></p>` 在浏览器里会变成什么结构？用 F12 的 Elements 面板查看。

<details>
<summary>参考</summary>

浏览器在 `ul` 前把 `p` 结束，后面还多出一个空的 `p`。`p` 只能装文字和内联元素，`ul` 是块级元素（PPT 第 15 页）。

</details>

自查本块（对照 `检查点/1-结构版/bear.html`）：

- 三级标题、两个列表、学名斜体、「无危」粗体都显示正确。
- 「更多...」和网址、媒体两行地址仍是普通文字。

## 三　链接、路径与媒体（PPT 第 16—20 页）

**练习 8　链接**

把「更多...」做成链接：点它在**新标签页**打开百度百科「棕熊」词条，原来单独一行的网址不再显示出来。

自查：「更多...」变成蓝色带下划线，点击后新开一个标签页。

<details>
<summary>参考</summary>

```html
<p><a href="https://baike.baidu.com/item/棕熊/370530" target="_blank">更多...</a></p>
```

网址从正文挪进 `href`；`target="_blank"` 让它在新标签页打开（PPT 第 17 页）。

</details>

**练习 9　图片与路径**

1. 把「media/brownbear.jpg」那一行换成图片，宽 320，图片显示不出来时显示「一头棕熊在河滩上行走」。
2. 判断：如果把 `bear.html` 挪进新建的 `pages` 文件夹，`src` 应改成什么？可以动手试，试完挪回。

<details>
<summary>参考</summary>

```html
<img src="media/brownbear.jpg" alt="一头棕熊在河滩上行走" width="320">
```

挪进 `pages` 后要写 `../media/brownbear.jpg`：相对路径从当前文件所在的目录找起，`../` 是上一级（PPT 第 18 页）。

</details>

**练习 10　视频**

把视频地址那一行换成带播放按钮的视频，宽 320；浏览器播放不了时显示「你的浏览器不支持播放视频。」

自查：按 F12 切到 Network 面板，刷新，能看到 `bear.html`、`brownbear.jpg` 和视频文件三行（PPT 第 19 页）。

<details>
<summary>参考</summary>

```html
<video src="https://content.codecademy.com/courses/freelance-1/unit-1/lesson-2/htmlcss1-vid_brown-bear.mp4" width="320" controls>你的浏览器不支持播放视频。</video>
```

视频不在本机，`src` 写完整 URL。

</details>

**练习 11　表格（选做）**

在「特征」一段后面加一张两列的表：项目、数值。三行数据：体长（英尺）5—9；体长（米）约 1.5—2.7；雄性比雌性大约 30%。

<details>
<summary>参考</summary>

```html
<table>
  <tr><th>项目</th><th>数值</th></tr>
  <tr><td>体长（英尺）</td><td>5—9</td></tr>
  <tr><td>体长（米）</td><td>约 1.5—2.7</td></tr>
  <tr><td>雄性比雌性</td><td>大约 30%</td></tr>
</table>
```

浏览器默认不画格线，看不到格线是正常的（PPT 第 20 页）。检查点 3-完成版里没有这张表。

</details>

自查本块（对照 `检查点/2-资源版/bear.html`）：「更多...」能点，照片显示，视频有播放器。

## 四　文档结构与语义化（PPT 第 21—24 页）

**练习 12　补上骨架**

给 `bear.html` 补上完整的文档骨架：声明 HTML5；页面语言是简体中文；编码 UTF-8；手机上按屏幕宽度显示；标签页标题「棕熊」。前面标好的内容全部放进 `body`。

提示：在空白处输入 `!` 再按 Tab，VS Code 会生成骨架，把 `lang` 改成 `zh-CN`、`title` 改成「棕熊」，再把内容挪进 `body`。

自查：浏览器标签页显示「棕熊」，不再是 `bear.html`。

<details>
<summary>参考</summary>

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>棕熊</title>
  </head>
  <body>
    ……前面标好的全部内容……
  </body>
</html>
```

</details>

**练习 13　按意思分区**

用语义化标签把 `body` 里的内容分区：全页标题是页头；其余是正文；正文按「关于棕熊」「栖息地」「媒体」分成三块。

自查：页面看起来没有变化。按 F12 打开 Elements，`body` 下是页头和正文，正文里有三块。

<details>
<summary>参考</summary>

```html
<header>
  <h1>棕熊</h1>
</header>

<main>
  <section>
    <h2>关于棕熊</h2>
    ……
  </section>
  <section>
    <h2>栖息地</h2>
    ……
  </section>
  <section>
    <h2>媒体</h2>
    ……
  </section>
</main>
```

页面不变是正常的：语义化标签说清「这一块是什么」，不改样子（PPT 第 24 页）。

</details>

**练习 14　源代码与元素树**

1. 先判断：删掉 `<html lang="zh-CN">`、`<head>`、`</head>`、`<body>`、`</body>`、`</html>` 六行，标签页标题和页面会变吗？Elements 面板里还有 `html`、`head`、`body` 吗？
2. 删掉、保存、刷新，按 Ctrl+U 看源代码，再看 Elements，验证判断。
3. 按 Ctrl+Z 恢复六行，保存。

<details>
<summary>参考</summary>

页面和标签页都不变；Elements 里三层都在，是浏览器补的，只有 `html` 上的 `lang` 没了。Ctrl+U 看到的是文本，Elements 看到的是浏览器解析出的树（PPT 第 23 页）。

</details>

自查本块：与 `检查点/3-完成版/bear.html` 对照，结构一致即可，缩进、空行不必相同。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| `explorer.exe .` 没反应 | 在资源管理器地址栏输入 `\\wsl$`，进 Ubuntu，再依次进 `home`、你的用户名、`work`、`html-bear` |
| 改名后 VS Code 里没有标签着色 | 文件名实际是 `bear.html.txt`。在 VS Code 里重命名，删掉 `.txt` |
| 刷新后页面没变 | 没保存：VS Code 标签上有圆点。按 Ctrl+S 再刷新 |
| 中文显示成乱码 | 文件没按 UTF-8 保存。点 VS Code 右下角的编码，选「通过编码保存」「UTF-8」 |
| 视频只有黑框，不播放 | 视频在外网服务器上，网络不通时取不到，不影响练习 |
| 点「更多...」打开的地址以 `file:///` 开头 | `href` 漏写了 `https://`，被当成相对路径 |
| 后面整页都变成粗体或斜体 | 有结束标签漏写了。从变样的地方往前找 |
